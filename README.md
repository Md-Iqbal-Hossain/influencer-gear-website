# Influencer Gear 📸

Influencer Gear is a product showcase landing page built with **HTML5** and **CSS3**. It features a modern layout designed to showcase influencer and content creation equipment through an engaging hero section and a collection of product cards.

## ✨ Features

- **Navigation Bar** — Provides easy navigation across the page.
- **Hero Section** — Introduces the platform with an attractive banner.
- **Popular Collections** — Displays products in an organized card layout.
- **Product Cards** — Showcases product images, names, prices, and ratings where available.
- **Footer** — Includes additional information and navigation links.
- **Flexbox & CSS Grid** — Organizes page content and product cards into structured layouts.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid

## 📂 Project Sections

- Navbar
